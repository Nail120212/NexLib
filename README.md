# NexLib

NexLib is a repository containing a collection of Roblox UI libraries that are free to use and explore.

Most of the UI libraries were created by **Nexxzel**, while some are modified or based on existing libraries.

## Credits

- **Footegues** — All icons are from the Footegues Icon Pack.
- **King Rua** — Base of **Shitty Banana** and **KingBanana**.
- **Obsidian UI** — Inspiration and base used for **KingBanana**.

## About

This repository is mainly for experimenting with, sharing, and organizing different Roblox UI libraries.

All credits belong to their respective creators and original authors.
